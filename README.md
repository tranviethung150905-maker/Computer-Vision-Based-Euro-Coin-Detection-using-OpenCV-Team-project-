# Computer-Vision-Based-Euro-Coin-Detection-using-OpenCV-Team-project-

A computer vision system developed using OpenCV and Python to detect Euro coins and classify their denomination based on their radius and color.

## Features

- Euro coin detection using the Hough Circle Transform
- Automatic calibration of Hough Circle Transform parameters for different camera distances
- Coin denomination classification using radius and color features
- Rule-based classification to distinguish coins from non-coin objects

## Technologies

- Python
- OpenCV
- Computer Vision
